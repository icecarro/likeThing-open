# 用户侧输入模板

把主问卷 + 性格问卷的结果合成下面这个 JSON，再交给模型。

```text
【测评结果】
才能：{talents}
价值观：{values_rank}｜工作目的：{purpose}
行业（20→10→5→2）：{trail}
深耕：{deep_fields}
细分：{subs_by_field}
性格：{mbti_type}（EI {ei} / SN {sn} / TF {tf} / JP {jp}）
星座：{zodiac}（文化参考，最多一句）
开放题原话：
1. {q40}
2. {q41}
3. {q42}

【候选岗位（已按 才能60% + 行业25% + 性格15% 排好）】
{jobs}

【本次要求】
按 system.md 的分析顺序，输出 JSON。重点写 cross：3–5 条只属于这个人的判断。
```

## 注意

- `talents` 只给分数和置信度，不要给结论——结论让模型自己下。
- 开放题原话必须原样传入，不要改写、不要概括。
- 性格只传四维分数和类型，不传描述文字，避免模型照抄。
- 星座传名字和关键词即可，不要传整套描述。
