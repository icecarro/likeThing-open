## 2. 为什么 9.9 不行

小红书薯条实测：约 109 元 → 9239 曝光 / 1066 阅读 / 20 条私信咨询（高客单案例，测评类要打对折）。

| 环节 | 中性假设 |
|---|---|
| 1000 阅读 → 私信 | 10 条（1%） |
| 私信 → 付费 | 25% |
| 单笔获客成本 | 108 ÷ 2.5 ≈ **43 元** |
| 9.9 收入 | 每单亏约 33 元 |
| 39.9 收入 | 毛利约 36 元，打平 |
| 49.9–69 收入 | 才有健康利润 |

**9.9 只在「纯自然流量、零投放」下成立。** 而本项目要用收入继续投推广，所以必须 ≥ 39.9。

## 6. 「收入全投推广」成立的条件

```
ROI = 单用户收入 ÷ 单用户获客成本 > 1
```

三条路，满足任一条即可持续：

1. 自然流量占比 ≥ 60%（内容够强，广告只是加速器）
2. 分享带来的新用户 ≥ 付费用户的 50%（k 因子 ≥ 0.5）
3. 同一批用户叠加零边际收入（深度版 / 1v1 / 企业版）

**阶段 0 的任务就是测出第 1 条能不能成立**——如果自然流量占比低于 40%，说明内容能力不够，先别投钱。
