# 07 · 风险与合规

> 这一份是「别把项目做死」的清单。每条都要在执行前过一遍。

---

## 1. 平台合规

### 1.1 小红书

| 风险 | 规则 | 应对 |
|---|---|---|
| 导流微信 | 笔记/评论/私信发微信号、二维码会被限流封号 | 首选小红书个人店站内成交；次选二维码**图片**，且不在公开内容里出现 |
| 测评类内容 | 平台对「测试/测评」审核波动 | 定位写「职业方向」「自我认知」，不写「心理测评」 |
| 绝对化用语 | 广告法禁「最/第一/保证」 | 全文禁用词表 |
| 医疗暗示 | 不得暗示诊断、治疗 | 不碰抑郁、焦虑、人格障碍 |

### 1.2 微信小程序（阶段 1）

| 项 | 规则 | 应对 |
|---|---|---|
| 主体 | 个人主体可开虚拟支付，需类目含「工具」 | 先按工具类目报，被驳回再改个体工商户 |
| 虚拟支付 | 必须走小程序虚拟支付，不得引导外部支付 | iOS 抽 12%、安卓 1%，已计入定价 |
| 月限额 | 个人主体月支付限额 10 万 | 到 8 万就准备升级主体 |
| 备案 | 小程序需 ICP 备案 | 提前 2–3 周办 |

### 1.3 抖音（阶段 3）

| 项 | 规则 | 应对 |
|---|---|---|
| 娱乐测试类目 | 不可接支付、单笔超 1 元不通过 | 不做 9.9，只做免费版 + 激励视频 |
| iOS 虚拟支付 | 禁止 | iOS 端只做免费内容 |
| 类目资质 | 泛知识类需企业主体 | 阶段 3 前注册个体户/公司 |

## 2. 版权（最重要的一条）

| 风险 | 说明 | 应对 |
|---|---|---|
| 照搬 90 问 | 书末问题清单受著作权保护，商用 + 大规模投放 = 高风险 | **题目 100% 自研改写**，只借鉴方法不抄原文 |
| 照搬 100 例清单 | 词表同样受保护 | 自建词表，措辞重写，数量与分类可参考 |
| 冒用背书 | 不能写「官方授权」「八木仁平推荐」 | 可写「方法灵感来自自我认知法」，不加书名做背书 |
| 商标 | 盖洛普、MBTI 是注册商标 | 全文不出现 |

**判断标准**：把书合上，用自己的话重写一遍，还能不能测出来？能，就合规。

## 3. 内容合规

**禁用词**：最、第一、保证、一定能、包就业、稳赚、心理测试、诊断、抑郁、焦虑症、MBTI 官方、盖洛普。

**必须有的免责**：
> 本报告基于你的自评回答生成，用于自我探索与职业方向参考，不构成心理诊断或就业承诺。

## 4. 隐私与未成年人

- 不收集手机号、身份证、住址
- 原始答案保留 90 天，可应要求删除
- 报告用编号，不用真名
- 首页标注「18 岁以上」
- 不做学生低龄市场（付费能力弱 + 合规敏感）

## 5. 运营风险

| 风险 | 表现 | 预案 |
|---|---|---|
| 报告像算命 | 用户说「这不就是巴纳姆效应」 | 证据引用 + 阴影面 + 7 天实验 |
| 交付延迟 | 48h 变 96h | 承诺 48h、实际 24h 出，留缓冲 |
| 退款纠纷 | 虚拟服务交付后难退 | 首次不满意免费重做一次 |
| 单点依赖 | 只有一个小红书号 | 阶段 2 起做账号矩阵 |
| 内容枯竭 | 发了 20 条没选题 | 90 问 + 5 误区 = 95 条选题库 |
| 差评扩散 | 一条差评影响转化 | 前 10 份逐份人工过，主动要反馈 |
