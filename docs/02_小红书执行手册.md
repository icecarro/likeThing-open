### 统一结构（每条照这个写）

```
封面（大字痛点）
  ↓
第 2 页：3 个「你是不是也这样」的具体场景
  ↓
第 3 页：一个反常识观点（为什么你努力了还是迷茫）
  ↓
第 4 页：报告目录截图 + 一页脱敏示例
  ↓
第 5 页：CTA ——「想测的，私信我『擅长』」
```

### 笔记 1 全文（可直接发布）

> **干了 5 年还是不知道自己擅长什么，真的不是你的问题**
>
> 上周有个读者私信我，说她做了 5 年运营，每天加班到 10 点，升职加薪都有，但一想到还要再干 5 年，就觉得喘不过气。她问我：是不是我太矫情了？
>
> 我说不是。你只是从来没被问过一个问题——**你做什么事的时候，是不费劲的？**
>
> 我们从小被训练的是「补短板」：数学不好补数学，不会说话练演讲。但工作 5 年以后你会发现，真正让你脱颖而出的，从来不是补起来的那块板，是你天生就不费劲的那块。
>
> 我把这个叫「擅长的事」。它不是技能（会 Excel、会写文案），是你**做事的习惯**：
> · 别人觉得乱的资料，你顺手就能理成一张表
> · 一群人都没头绪时，你总能先说出「那我们先做这个」
> · 你写东西的时候，时间过得特别快
>
> 这些事你从来没当成优点，因为它们对你太容易了。但正是这些「太容易」，决定了你适合什么样的工作。
>
> 我整理了一份 45 题的测评，8 分钟。最后会给你：3 个你天生擅长的事 + 5 个具体到岗位的方向 + 一个 7 天能做的验证。
>
> 不是「你是 XX 型人格」那种，是能落到「下周投什么岗」那种。
>
> 想测的，私信我「擅长」。

## 3. 三条视频脚本

### 脚本 A（35 秒，共鸣）

| 时间 | 画面 | 台词/字幕 |
|---|---|---|
| 0–3s | 地铁/工位 | 你有没有过这种时刻 |
| 3–10s | 对着电脑发呆 | 周一早上睁眼第一个念头是「不想上班」。不是累，是空 |
| 10–20s | 切近景 | 你以为是我不够努力。其实是你一直在用不擅长的方式工作 |
| 20–30s | 字幕板 | 擅长的事不是技能，是你做起来不费劲、别人却觉得难的事 |
| 30–35s | 报告截图 | 8 分钟测出来，私信我「擅长」 |

### 脚本 B（45 秒，干货涨粉）

「三个问题，判断你擅长什么：
第一，过去半年，哪件事做完你不但不累，还想再来一次？
第二，别人经常找你帮什么忙？注意，是**经常**，不是偶尔。
第三，什么事你觉得『这有什么难的』，但身边的人就是做不好？
第三个问题最准——因为对你太容易的事，你从来不觉得它是优点。」

### 脚本 C（40 秒，观点引评论）

「为什么你越努力越迷茫？
因为你在用『补短板』的思路选工作。
公司招人不是招最全面的，是招在某件事上最不费劲的。
你花了五年补的那块板，别人天生就有。而你天生有的那块，你从来没拿出来卖过。」

## 4. 广告语与禁用词

**主 slogan**：不是你不努力，是你还没站在自己擅长的地方。

备选：
- 先看清自己，再选职业
- 8 分钟，找到你天生擅长的工作方式
- 你不需要变成别人，你需要用对自己

**禁用词**（限流/违规）：最、第一、保证、一定能、包就业、心理测试、抑郁、焦虑症、MBTI 官方、盖洛普、「加微信/加V」。

## 5. 薯条投放

**步骤**：发布 → 等 24h 自然流量 → 达标才投 → 笔记右上角「薯条」→ 选目标 → 选时长 → 付款。

| 参数 | 设置 | 理由 |
|---|---|---|
| 投放门槛 | 自然阅读 ≥ 1000、互动率 ≥ 5% | 冷启动笔记投了就是烧钱 |
| 金额 | 108 元/条（750 薯条，最低档） | 够验证不浪费 |
| 目标 | 先「阅读量」；有「私信咨询」选项再切 | 私信目标更贵，数据没跑通前别用 |
| 时长 | 6 小时，晚 8–11 点 | 目标人群活跃时段 |
| 定向 | 智能推荐优先；不行再 女 + 23–32 岁 + 一二线 | 精准定向样本太小 |
| 总预算 | 300 元（2–3 条） | 留 100 元杂费 |

**止损**：投后 24h，封面点击率 < 10% 或平均阅读时长 < 1/3 → 停投，换封面重发，不加钱。

## 6. 私信承接 SOP

| 时点 | 动作 | 话术 |
|---|---|---|
| 收到私信 | 自动回复 | 「谢谢关注～想了解测评回『1』，想先看报告长什么样回『2』」 |
| 2 小时内 | 人工发说明 | 「这份测评 45 题、8 分钟，出 3 个你擅长的事 + 5 个具体岗位方向 + 7 天验证。39.9，48 小时内交付，报告发你后 7 天内可以随时文字问我。先发你一页示例看看？」 |
| 付款后 | 发问卷 | 「链接在这，中途退出会保存，答完回我一声。开放题写具体一点，报告会引用你自己的话。」 |
| 提交后 | 质检 | 开放题敷衍 → 追问「能举个具体例子吗」，别硬出报告 |
| 48h 内 | 交付 | 长图 + PDF（之后 7 天内文字答疑） |
| 第 7 天 | 回访 | 「那个 7 天实验做了吗？卡在哪一步？」 |

**收款路径**：
1. 首选：小红书个人店，上架「1 对 1 职业优势深度报告」，站内成交，2% 手续费，零导流风险。
2. 备选：私信发二维码**图片**（不发文字链接），微信收款码收款。

## 7. 交付流程

| 步骤 | 动作 | 工具 |
|---|---|---|
| 1 | 问卷回收 | 腾讯问卷 |
| 2 | 导出答案 JSON | 问卷后台 |
| 3 | 规则引擎打分 | 本地 Python 脚本（阶段 0 可手工） |
| 4 | LLM 生成报告 | DeepSeek API |
| 5 | 质检 | 6 条脚本检查 |
| 6 | 渲染长图 + PDF | HTML + Playwright |
| 7 | 发送 + 语音解读 | 微信 |

**隐私**：报告里不出现真实姓名，用编号；问卷数据不外传；交付后 90 天删除原始答案（或按用户要求）。
