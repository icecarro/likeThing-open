# 01 · 阶段 0：小红书 4 周市场验证

> 目的：用最低成本回答一个问题——**有没有人愿意为一份 AI 深度职业报告付 39.9 元？**
> 预算：400 元以内　｜　周期：4 周　｜　产出：GO / NO-GO 决策书

---

## 1. 要验证的 4 个假设

| # | 假设 | 判定线 | 不达标说明 |
|---|---|---|---|
| H1 | 内容能低成本触达「职业迷茫」人群 | 单条自然阅读 ≥ 1000，互动率 ≥ 5% | 选题或封面有问题 |
| H2 | 有人愿意为 39.9 的 AI 报告付费 | 2 周付费 ≥ 8 单 | 价值感不够，或人群不痛 |
| H3 | 私信咨询能转化成付费 | 咨询→付费 ≥ 20% | 话术/定价/信任有问题 |
| H4 | 报告让人觉得值并愿意推荐 | 满意度 ≥ 4.2/5，愿意推荐 ≥ 60% | 产品要重做，不是运营问题 |

**注意**：H4 不达标时，不要加大投放。先改报告。

## 2. 实验设计

| 项 | 设置 |
|---|---|
| 账号 | 1 个新号，定位「帮你看清自己擅长什么」 |
| 笔记 | 5 条（3 个场景 + 2 个封面 A/B） |
| 场景 | A 转行迷茫 / B 应届不知道投什么岗 / D 想做个人 IP 不知道定位 |
| 薯条 | 108 元/条，只投自然数据达标的笔记，总计 300 元 |
| 承接 | 小红书个人店（首选）或 私信 + 二维码收款 |
| 问卷 | 腾讯问卷，45 题，支持断点续答 |
| 交付 | 长图 + PDF，48 小时内；报告后 7 天内文字答疑（不语音） |
| 出报告 | AI 生成 + 人工校准，每份 40–60 分钟 |

**为什么不做 A/B 定价**：8–15 单的样本量做价格 A/B 没有统计意义。首轮只测「单一价格下的转化率」。

## 3. 四周排期

| 周 | 我负责 | 你负责 | 周验收 |
|---|---|---|---|
| W1 | 5 条笔记全文、45 题问卷、报告模板 v0.1、长图脚本 | 注册账号、完善主页、发第 1 条 | 账号可私信、第 1 条笔记发布 |
| W2 | 出前 3 份报告、调 Prompt | 接私信、收款、发剩余笔记、投薯条 | 至少 3 单付费 |
| W3 | 批量出报告、整理反馈 | 交付、回访、收集晒图 | 累计 8 单 |
| W4 | 数据分析、决策书 | 补最后几单、确认结论 | GO / NO-GO |

## 4. 指标看板（每天记一行）

| 日期 | 笔记 | 曝光 | 阅读 | 赞藏评 | 私信 | 付费 | 收入 | 备注 |
|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |

核心派生指标：

- 封面点击率 = 阅读 ÷ 曝光（目标 ≥ 10%）
- 互动率 = (赞+藏+评) ÷ 阅读（目标 ≥ 5%）
- 私信率 = 私信 ÷ 阅读（目标 ≥ 1%）
- 转化率 = 付费 ÷ 私信（目标 ≥ 20%）
- CAC = 薯条花费 ÷ 付费单数（目标 ≤ 20 元）

## 5. 决策规则

| 结果 | 判定 | 下一步 |
|---|---|---|
| 付费 ≥ 8 且 转化 ≥ 20% 且 ≥ 3 人问「能不能更深入」 | **GO** | 进入阶段 1，做小程序 |
| 付费 3–8 | **加测** | 再投 300 元，只改场景/封面/价格 |
| 曝光 ≥ 2 万、咨询 ≥ 20、付费 < 3 | **NO-GO（价值问题）** | 重做报告，不碰产品 |
| 咨询 < 5 | **NO-GO（内容问题）** | 换选题，重做封面 |

## 6. 市场天花板估算

```
潜在市场 = 目标人群 × 触达率 × 付费率 × 客单价
```

| 变量 | 取值 | 来源 |
|---|---|---|
| 小红书月活 | 约 3 亿 | 公开报道 |
| 22–32 岁职场人 | 约 8000 万 | 人口结构估算 |
| 职业迷茫渗透率 | 30% → 2400 万 | 经验值 |
| 付费率 | 0.3%–1% → 7–24 万人 | 保守估算 |
| 客单价 | 39.9 | 定价决策 |
| **年上限** | **280–960 万元** | 内容产能足够时的理论上限 |

**第一年目标定 30–50 万流水更现实。**

## 7. 风险与预案

| 风险 | 预案 |
|---|---|
| 笔记审核波动 | 多备 2 条，别把宝押一条 |
| 私信回复慢流失 | 自动回复 + 2 小时内人工接 |
| 报告质量不稳招差评 | 前 10 份逐份人工过一遍 |
| 导流被限流 | 优先用小红书店铺站内成交 |
| 交付超时 | 承诺 48h，实际 24h 出，留缓冲 |
