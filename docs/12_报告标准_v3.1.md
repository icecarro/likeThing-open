# 12 报告标准 v3.3（定版）

> 2026-10-29 定版。以用户认可的那份「准确」报告为基准，按《如何找到想做的事》校准。
> v3.2：05 改为「从组合推导实现手段」，带形态（打工/自由职业/小生意/内容）。
> v3.3：06「如果你更想自己做事」改为**先卖后做**：服务型优先、给具体价格、写明前 3 个客户从哪来。
> 改动本文件必须同步改 `prompts/system.md` 与 `scripts/generate.py` 的 `check()`。

## 一、方法论（不可改）

```
公式1：喜欢的事 × 擅长的事 = 想做的事
公式2：喜欢的事 × 擅长的事 × 重要的事 = 真正想做的事
```

- 重要的事（Why）：价值观 → 工作目的
- 擅长的事（How）：**习惯层面的长处**，不是技能
- 喜欢的事（What）：愿意持续投入的**领域**

顺序：重要 → 擅长 → 喜欢 → 组合 → 用工作目的筛 → 最后才是手段（岗位/生意）。

## 二、章节结构（固定）

| 序 | 章节 | 必须包含 |
|---|---|---|
| 01 | 先说结论 | 最硬原话 → 说明什么 → 分数作证 → 价值观 → 「这份报告不做什么」 |
| 02 | 能力盘点 | MBTI + 星座（一句）+ 3 个才能卡（原话 / 位置 / 用错了会怎样） |
| 03 | 取舍 | 价值观排序 + 工作目的 |
| 04 | 领域地图 | 漏斗 + 「意愿证据，不是能力证据」 |
| 04+ | 喜欢 × 擅长 | 3–5 条组合 + keep 筛选 |
| 05 | 实现手段 | 2–3 条，由组合推导；角色名带"怎么用才能"；标形态（打工/自由职业/小生意/内容）；日常/为什么是你/门槛/代价/第一步 |
| 05b | 自己做事 | 2–3 条，**先卖后做**：服务型优先、谁付钱、交付什么、首单价格、前 3 个客户、启动成本、风险、30 天实验 |
| 06 | 常见误区 | 信号 + 怎么办 |
| 07 | 90 天提示词 | 可复制，带才能证据 |
| 08 | 宏观环境 | 2–3 条 |
| 附 | 命理参考 | 文化参考，不参与排序 |

## 三、写法密度（最重要）

1. **结论从用户原话开始**，不从定义或分数开始。
2. **才能卡三段**：原话 → 你该去的位置 → 用错了会怎样（具体到组织行为或收入）。
3. **每条 cross 带一个「会发生的事」**，不是纯评价。
4. **结论必须有边界声明**：「这份报告不劝你……它只回答一个问题」。
5. 禁止把分数当主语。
