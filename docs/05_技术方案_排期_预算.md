# 05 · 技术方案、排期与预算

---

## 1. 阶段 0：零开发（4 周）

| 环节 | 工具 | 成本 |
|---|---|---|
| 问卷 | 腾讯问卷（免费、无广告、支持逻辑跳转） | 0 |
| 收款 | 小红书个人店 / 微信收款码 | 0 / 2% |
| 打分 | 本地 Python 脚本 | 0 |
| 报告生成 | DeepSeek API + Jinja2 模板 | < 1 元/份 |
| 长图/PDF | Playwright 截图 | 0 |
| 分发 | 微信 | 0 |

**结论：阶段 0 不需要服务器、不需要域名、不需要小程序。**

## 2. 阶段 1：微信小程序（6 周）

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | Taro 3 + React + TypeScript | 一套代码出微信小程序 / H5 / 抖音小程序 |
| 状态 | Zustand | 轻量 |
| 后端 | Python FastAPI | 与现有 Python 环境一致 |
| 数据库 | PostgreSQL | 答案、报告、订单 |
| 缓存 | Redis | 会话、限流 |
| AI | DeepSeek / Qwen API | JSON 结构化输出 |
| 渲染 | 服务端 HTML → 长图 | 复用阶段 0 模板 |
| 部署 | 阿里云轻量 2C2G + 备案域名 | 见下表 |
| 监控 | 简单日志 + 每日报表 | 先不上 APM |

## 3. 服务器与域名

| 阶段 | 需要什么 | 费用 |
|---|---|---|
| 0 | 无 | 0 |
| 1 | 域名 1 个 + ICP 备案 + 轻量 2C2G | 域名 ~60/年；服务器 60–100/月（新客首年 99–200） |
| 2 | 2C4G + OSS + CDN | 200–300/月 |

**备案**：个人可办，2–3 周，与小程开发并行。小程序要求 HTTPS 域名并加入白名单。

## 4. 排期

| 阶段 | 周 | 关键任务 | 里程碑 |
|---|---|---|---|
| 0 | W1–W4 | 小红书验证 | GO / NO-GO |
| 1 | W5–W10 | 小程序开发（并行备案） | 上线、能收款、能出报告 |
| 2 | W11–W18 | 内容矩阵 + 投放 | 月 1000 单 |
| 3 | W19–W26 | 抖音小程序、职业库、1v1 | 月流水 ≥ 5 万 |

**最短路径**：小红书 4 周见结论 → 小程序 6 周上线 → 约 10 周有正式产品；到月流水稳定 4–6 个月。

## 5. 预算

| 项 | 阶段 0 | 阶段 1 | 阶段 2/月 |
|---|---|---|---|
| 薯条/投放 | 300 | 1000 | 3000–8000 |
| 服务器域名 | 0 | 300 | 250 |
| API | 50 | 100 | 500 |
| 设计/素材 | 50 | 300 | 500 |
| 杂费 | 100 | 200 | 500 |
| **合计** | **500** | **约 2000** | **约 5000** |

## 6. 数据与隐私

- 问卷原始答案保留 90 天，交付后可按用户要求删除
- 报告不出现真实姓名，用编号
- 不收集手机号（需要联系就用小红书/微信现有会话）
- 未成年人：首页标注「18 岁以上」，不做学生低龄市场
- 隐私政策页面（阶段 1 必须有）

## 7. 数据回流

| 数据 | 用途 |
|---|---|
| 每题作答分布 | 淘汰区分度低的题 |
| 开放题原文 | 报告引用 + 内容素材 |
| 用户满意度 + 「哪句最像你」 | 迭代 Prompt |
| 付费转化路径 | 优化落地页 |
| 报告被转发次数 | 评估传播力 |
