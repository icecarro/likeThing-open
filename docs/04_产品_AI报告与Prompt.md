# 04 · 产品形态、AI 报告与 Prompt

> 原则：**规则引擎定结论，LLM 只写叙事。** 结论稳定可复现，成本 0.1–0.3 元/份。

---

## 1. 产品流程

```
笔记 → 私信 → 付费 39.9 → 45 题问卷 → 规则引擎打分 → 职业库匹配
                                                      ↓
                                            LLM 生成 6 模块报告
                                                      ↓
                                             质检（6 条硬规则）
                                                      ↓
                                     HTML 模板渲染 → 长图 + PDF
                                                      ↓
                                          微信发送长图 + PDF（7 天内文字答疑）
```

## 2. 报告六个模块（3500–6000 字）

| # | 模块 | 内容 | 长度 |
|---|---|---|---|
| 1 | 一句话定性 | 你是谁、你靠什么吃饭 | 100 字 |
| 2 | 你的使用说明书 | 3 个天赋（定义 / 你的证据 / 用错地方的代价） | 1200 字 |
| 3 | 你的指南针 | 价值观排序 + 一句「工作目的」 | 600 字 |
| 4 | 你想去的地方 | 3 个热情领域 | 500 字 |
| 5 | 五个具体岗位 | 岗位名 / 行业 / 日常一天 / 为什么是你 / 门槛 / 薪资 / 90 天路径 | 2000 字 |
| 6 | 你的雷区 + 7 天实验 | 3 个坑 + 每天一个 30 分钟动作 | 800 字 |

**模块 5 是全篇的价值锚点**，必须具体到「什么公司、什么岗位、先做什么」。

## 3. AI 三段式

| 段 | 谁做 | 输入 | 输出 | 为什么 |
|---|---|---|---|---|
| ① 推导 | 规则引擎（代码） | 45 题答案 | 标签分 + Top8 岗位 | 可复现、可解释 |
| ② 表达 | LLM | 标签 + 原话 + 岗位候选 | 6 模块 JSON | 有温度、个性化 |
| ③ 质检 | 代码 | 报告 JSON | 通过 / 打回 | 防幻觉、防废话 |

**LLM 只能从候选岗位里选**，不允许自己发明岗位、公司、薪资数字。

## 4. System Prompt（可直接用）

```text
你是做了 8 年职业咨询的顾问，风格直接、具体、不灌鸡汤。
你的用户是 22-32 岁、工作 0-8 年、正在迷茫的中国人。

【硬性约束】
1. 你只能在给定的候选岗位里选择，不得发明岗位、公司、薪资。
2. 每一条关于用户的判断，必须引用至少 1 句用户原话或 1 个具体选项。
3. 禁止使用：你很优秀、潜力无限、相信自己、加油、一定是、保证、最。
4. 薪资必须写区间，并标注城市等级（一线/新一线/二线）。
5. 每个岗位的「90 天路径」必须写到具体动作：学什么、在哪个平台、投什么类型的公司、第几周做什么。
6. 不确定的地方，直接写「这一点需要你在实践中验证」，不要编。
7. 全文 3500-6000 字，中文，口语，短句。

【输出格式】
严格输出 JSON，字段见 schema，不要输出 JSON 以外的任何内容。
```

## 5. User Prompt 模板

```text
【用户画像】
才能标签（含分数）：{top_talents}
价值观排序：{values_rank}
热情领域：{domains}
置信度提示：{confidence_notes}

【用户原话】
1. {open_q1}
2. {open_q2}
3. {open_q3}

【候选岗位（只能从这里选 5 个）】
{jobs_top8}

【本次要求】
生成 6 个模块：summary / manual / compass / domains / jobs / pitfalls_and_experiment
```

## 7. 质检六条（代码校验，不通过重跑）

| # | 检查 | 不通过处理 |
|---|---|---|
| 1 | 岗位是否都在候选库内 | 删除并重生成 |
| 2 | 每个天赋是否引用了原话 | 重跑该模块 |
| 3 | 是否出现禁用词 | 替换/重跑 |
| 4 | 每个岗位是否有 90 天路径 | 重跑该岗位 |
| 5 | 总字数是否在 3500–6000 | 扩写/精简 |
| 6 | 是否出现「保证/一定/最」 | 重跑 |

## 8. 报告示例片段（模块 2）

> **天赋 2：你能在混乱里先看见「结构」**
>
> 你说的那句话我记下来了：「一堆人讨论两小时没结论，我画了个表大家就都明白了。」
>
> 这不是「会做表」。这是**在信息还没成型的时候，你就能看见它该长什么样**。别人看到的是 20 条零散意见，你看到的是 3 个分类、1 个优先级。
>
> 用对了，你是那个让会议提前半小时结束的人；用错了，你会变成「什么都你来整理」的那个人——最后你成了团队的中控台，却没人为你的整理付钱。
>
> 判断标准：如果你的工作里，**整理和结构化占了 50% 以上但不被计入考核**，你就在被消耗。

## 9. 成本

| 项 | 单份成本 |
|---|---|
| LLM 生成（约 5000 字输出） | 0.15–0.40 元 |
| 长图渲染 | ≈ 0 |
| 人工校准（阶段 0） | 10–20 分钟 |
| **合计（阶段 0）** | **< 1 元 + 人工** |

阶段 1 自动化后，单份边际成本 < 0.5 元。
