# 03 · 问卷设计规范（45 题）

> 这一版回答一个关键问题：**为什么是 45 题，而不是 90 题或 300 题？45 题怎么设计？**

---

## 0. 先把三样东西分清楚

| | 是什么 | 数量 | 在系统里的角色 |
|---|---|---|---|
| **90 问** | 开放式自问提纲（书末附表） | 90 | **不进问卷**。只做开放题素材、内容选题、报告写作参考 |
| **100 例清单 ×3** | 词汇表 / 选项池 | 300 个词 | **不是题目**。是选项来源、标签命名、报告术语 |
| **45 题问卷** | 测量工具 | 45 | 唯一进产品的东西 |

所以「书里有上百道题」是误解——那是**词库**。真正的问卷是 45 题，从词库里选出约 **30 个标签**，每个标签用 **1–3 道题**去测。

## 1. 45 题怎么分配

| 模块 | 题数 | 题型 | 测什么 |
|---|---|---|---|
| 才能（How） | 18 | 6 情境四选一 + 12 行为频率 | 6 个才能簇，每簇 3 题（1 情境 + 2 频率） |
| 价值观（Why） | 12 | 4 情境 + 4 排序 + 4 多选 | 4 组价值观，每组 3 题 |
| 热情（What） | 9 | 9 行为频率 | 9 个领域，每领域 1 题 |
| 开放题 | 3 | 短文本 / 语音 | 证据引用 |
| **计分合计** | **42** |  |  |
| 校验题（不计分） | 3 | 反向题 / 重复题 / 注意力题 | 防敷衍 |
| **总题数** | **45** |  |  |

**关键比例**：才能 43%、价值观 29%、热情 21%、开放 7%。才能权重最高，因为报告的核心卖点是「你擅长什么」。

## 2. 测量模型

### 2.1 才能：6 个簇

| 簇 | 含义 | 典型标签（来自 100 例清单） |
|---|---|---|
| 思考型 | 分析、洞察、抽象、找规律 | 看穿本质、逻辑拆解、归纳体系 |
| 创造型 | 发散、审美、从 0 到 1 | 想新点子、把想法做成样子、审美判断 |
| 连接型 | 共情、沟通、影响他人 | 听出弦外之音、让人愿意说、凝聚人 |
| 执行型 | 推进、落地、秩序 | 把事推到底、建立流程、盯细节 |
| 探索型 | 好奇、学习、试错 | 快速上手新东西、不怕试错、跨界 |
| 稳定型 | 专注、耐心、长期 | 坐得住、持续打磨、守承诺 |

### 2.2 价值观：4 组

成就成长 / 自由自主 / 关系贡献 / 安全稳定。用排序题测**优先级**，而不是打分。

### 2.3 热情：9 个领域簇

科技与数据、商业与增长、内容与表达、教育与成长、健康与身心、艺术与审美、自然与手艺、社会与公益、生活与关系。

### 2.4 输出

- 才能 Top 3 簇 + 簇内 Top 标签（共 3–5 个具体标签）
- 价值观 4 组排序 → 合成一句「工作目的」
- 热情 Top 3 领域
- 每个结论带**置信度**（高/中/低）

## 3. 五种题型，各管什么

| 题型 | 用在哪 | 优点 | 缺点 |
|---|---|---|---|
| 情境四选一（forced choice） | 才能 8 题、价值观 4 题 | 抗社会赞许，逼出真实偏好 | 无法表达「都像」 |
| 行为频率 Likert（5 点） | 才能 10 题、热情 6 题 | 可量化，有客观锚点 | 有人会往高报 |
| 多选打勾（20 选 5） | 热情 6 题、价值观 3 题 | 快速覆盖词库 | 容易多选 |
| 排序拖拽（4 项） | 价值观 5 题 | 测优先级最有效 | 手机上略费力 |
| 开放题 | 3 题 | 报告的证据来源 | 有人不写 |

**强制选择是抗「巴纳姆效应」的核心**：不问「你善于沟通吗」，而是问「下面四种情况，哪种最像你」——四个选项都是正面特质，逼用户取舍。

## 4. 每题 10 条设计规范（附反例）

| # | 规范 | ❌ 反例 | ✅ 改法 |
|---|---|---|---|
| 1 | 一题只测一个标签 | 「你善于沟通又有领导力吗」 | 拆成两题 |
| 2 | 问行为，不问自评 | 「你擅长分析吗」 | 「过去 3 个月，有几次别人拿一堆乱数据找你理出头绪」 |
| 3 | 时间锚定 | 「你经常…」 | 「过去 3 个月，平均每周…」 |
| 4 | 具体场景 | 「你喜欢创造性工作吗」 | 「方案被否了，你第一反应是…」 |
| 5 | 选项互斥且穷尽 | 选项里同时有「经常」和「每周 3 次」 | 统一用频率刻度 |
| 6 | 避免社会赞许 | 「你愿意帮助同事吗」（谁都会选是） | 四选一，全是好特质 |
| 7 | 不双重问题 | 「你喜欢独立又有挑战的工作吗」 | 拆开 |
| 8 | 不引导 | 「优秀的人都善于规划，你…」 | 中性陈述 |
| 9 | 长度限制 | 题干 40 字 | 题干 ≤ 25 字，选项 ≤ 15 字 |
| 10 | 一屏一题 | 一页 10 题 | 手机一屏一题，进度条可见 |

## 5. 计分规则

### 5.1 题目 → 标签权重矩阵

每题输出 1–2 个标签的权重（0–1），存成 JSON：

```json
{
  "q07": { "tags": { "T03_看穿本质": 0.8, "T11_逻辑拆解": 0.4 } },
  "q08": { "tags": { "T05_把事推到底": 1.0 } }
}
```

### 5.2 标签得分

```
标签分 = Σ(选项分 × 权重) ÷ 该标签题数 × 20   → 0–100
```

### 5.3 置信度规则

| 条件 | 置信度 | 处理 |
|---|---|---|
| 该标签 ≥ 3 题且答案方差小 | 高 | 写进结论 |
| 2 题 | 中 | 写进结论，措辞留余地 |
| 1 题，或方差大 | 低 | 标「待验证」，不写死 |

### 5.4 价值观合成

排序题给 4/3/2/1 分，加权求和 → 第一组即「工作目的」方向，套模板生成一句话。

### 5.5 热情合成

多选命中领域 + 频率题强度，取 Top 3。

## 6. 三道开放题

| # | 题干 | 为什么问 | 怎么用 |
|---|---|---|---|
| 1 | 最近一次「做完不累、反而更有电」的事是什么？具体说说 | 才能的最强证据 | 报告里原文引用 |
| 2 | 别人最常找你帮什么忙？（要具体的，不是「什么都找我」） | 外部视角验证才能 | 与自评交叉验证 |
| 3 | 如果完全不用考虑钱，你想做什么？ | 热情与价值观 | 报告第 4 模块 |

限制：每道 ≤ 200 字，可选语音 60 秒，允许跳过 1 题（跳过要在报告里标注「此项缺失」）。

## 7. 防敷衍机制

- 3 道校验题：1 道反向题 + 1 道重复题（间隔 10 题）+ 1 道「本题请选第二个选项」
- 总答题时长 < 3 分钟 → 标记「低质量」，触发追问
- 开放题 < 10 字 → 追问一次
- Likert 直线作答（全是 5 分）→ 标记

## 8. 45 题够不够？（直接回答你的疑问）

### 8.1 精度与题量的关系

| 每簇题数 | Cronbach's α（经验值） | 能做什么 |
|---|---|---|
| 1 题 | 0.3–0.4 | 只能做趣味标签，不能做结论 |
| 2 题 | 0.55–0.65 | 粗分类 |
| **3 题** | **0.65–0.75** | **够做 Top3 排序** |
| 6 题 | 0.80–0.85 | 精细排序 |
| 12 题 | 0.90+ | 专业测评级 |

45 题 = 每簇 3 题，处于「够用」区间。

### 8.2 完成率与题量的关系（经验值）

| 时长 | 完成率 |
|---|---|
| 5 分钟 | 约 80% |
| **8–10 分钟** | **约 60%** |
| 20 分钟 | 约 35% |
| 40 分钟（盖洛普级） | 约 15% |

**39.9 元的产品，必须落在 60% 完成率这一档。** 90 题、40 分钟的产品对应的是 445 元的定价和完全不同的运营方式。

### 8.3 分层方案

| 产品 | 题量 | 时长 | 价格 | 交付 |
|---|---|---|---|---|
| 标准版 | 45 | 8–10 分钟 | 39.9 | Top3 + 5 岗位 |
| 深度版 | 90 | 20 分钟 | 99 | 加 12 个月路线 + 简历建议 |
| 1v1 版 | 45 + 访谈 | 60 分钟 | 199–299 | 人工解读 |

**结论：45 题不是「少」，是 39.9 元这个价位的最优解。** 想更准，不是把题变多，是加人工访谈。

## 9. 300 例清单的四种用法

1. **选项池**：多选打勾题从清单里抽 20 个词做选项
2. **开放题提示**：用户写不出来时，给「参考词云」
3. **报告术语**：统一用清单里的词，避免自造概念
4. **标签命名**：30 个标签直接对齐清单措辞，用户看起来眼熟

## 10. 建库七步

```
① 定 6 才能簇 / 4 价值观组 / 12 领域
② 每簇选 3–5 个标签，共约 30 个
③ 每个标签写 3 道候选题（多写，后面淘汰）
④ 配选项（四选一 / 频率 / 多选 / 排序）
⑤ 定「题目→标签」权重矩阵
⑥ 预测试 30–50 人：算 α、题总相关、重测信度
⑦ 淘汰区分度低的题，上线 v1
```

**预测试指标**：

| 指标 | 目标 |
|---|---|
| 每簇 Cronbach's α | ≥ 0.7 |
| 题总相关 | ≥ 0.3（低于则淘汰） |
| 重测信度（2 周后 10 人） | ≥ 0.7 |
| 单题完成时长 | ≤ 15 秒 |
