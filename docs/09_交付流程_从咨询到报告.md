# 09 · 交付流程：从一条私信到一份报告

> 回答一个具体问题：**客户来了，问卷怎么给他？他怎么答？怎么自动分析？结果怎么回去？**

---

## 1. 客户看到的只有四步

```
① 私信你「擅长」
② 收到一个链接（或二维码）→ 点开答题，9 分钟，中途退出答案还在
③ 提交 → 页面显示「48 小时内交付」
④ 微信收到：一张长图 + 一份 PDF；报告发出后 7 天内可以随时文字问我
```

客户不需要装任何东西，不需要注册账号，不需要下载 App。

## 2. 你这一侧：每天一次，10 分钟

```
腾讯问卷后台收到新答卷
   ↓ 导出 Excel（一次可导全部）
inbox/A001.xlsx
   ↓ 一条命令
python scripts/generate.py --excel inbox/A001.xlsx --id A001
   ↓ 40 秒后
out/A001/report.png + report.pdf
   ↓ 微信发送
客户
```

**为什么是「每天一次」而不是「提交即出」**：阶段 0 只有 8–15 单，实时性不值钱；为了实时性去搭服务器、买域名、做回调，是本末倒置。

## 3. 为什么阶段 0 不用小程序

| | 问卷 + 脚本 | 小程序 |
|---|---|---|
| 开发 | 0 天 | 6 周 |
| 备案 | 不需要 | 2–3 周 |
| 支付 | 小红书店铺 / 微信收款码 | 需虚拟支付资质 |
| 适合单量 | 8–15 单 | 1000+ 单 |
| 结论 | ✅ 阶段 0 | 阶段 1 |

**小程序不是不能做，是现在做会拖慢验证。**

## 4. 怎么把问卷交给客户

### 4.1 建卷（腾讯问卷，一次 2 小时）

| 步骤 | 动作 |
|---|---|
| 1 | 新建「问卷」，标题写「你的使用说明书 · 45 题」 |
| 2 | 第 0 题加一个填空：「你的微信昵称（方便我对上人）」 |
| 3 | 按 [`08_问卷v1_45题全文.md`](08_问卷v1_45题全文.md) 录 45 题 |
| 4 | 题型对应见 08 文档 G 节 |
| 5 | 设置：全部必答（开放题除外）、一页一题、显示进度条、允许修改答卷 |
| 6 | 提交后文案：「收到，48 小时内把报告发你。有开放题写得太简短的，我会单独问你。」 |
| 7 | 打开「微信通知」，有新答卷时你会收到提醒 |
| 8 | 生成二维码，存成图片 |

### 4.2 发卷的三种方式

| 方式 | 适用 | 注意 |
|---|---|---|
| **二维码图片**（首选） | 私信一对一 | 小红书私信发**图片**，不要发文字链接，容易被拦 |
| **短链** | 微信内转发 | 用 `wj.qq.com` 原始链接太长，可套一层短链 |
| **小红书店铺自动发货** | 站内成交 | 商品设置为虚拟服务，付款后自动发链接/二维码 |

### 4.3 三个坑

1. **私信发文字链接被限流** → 一律发二维码图片。
2. **客户用电脑打开** → 排序题在电脑上体验差，提醒「用手机填」。
3. **中途退出** → 腾讯问卷的断点续答依赖同一微信/设备，建卷后自己测一遍；不行就在设置里开「允许修改答卷」，让客户重新进。

## 5. 你这一侧的自动化流水线

```
inbox/A001.xlsx
   │ ① import：列名 → 题号，生成 answers.json
   ▼
answers.json
   │ ② score.py：规则引擎打分
   ▼
scores.json（标签分 + Top3 + 置信度 + 质量标记）
   │ ③ prompt_build：拼 System + User Prompt
   ▼
prompt.txt
   │ ④ LLM（DeepSeek）：输出 report.json
   ▼
report.json
   │ ⑤ check：6 条质检，不过就重跑
   ▼
report.json（合格）
   │ ⑥ render：HTML 模板 → 长图 + PDF
   ▼
out/A001/report.png / report.pdf / report.html
```

### 命令

```bash
# 样例（不用 API Key，规则引擎生成）
python scripts/generate.py --demo

# 真实客户：问卷导出的 Excel
python scripts/generate.py --excel inbox/A001.xlsx --id A001

# 或直接给 answers.json（问卷预览页导出的就是这种）
python scripts/generate.py --answers answers.json --id A001

# 接大模型（需要 DEEPSEEK_API_KEY）
python scripts/generate.py --excel inbox/A001.xlsx --id A001 --engine llm
```

两个引擎：

| 引擎 | 说明 | 何时用 |
|---|---|---|
| `offline`（默认） | 规则 + 模板 + 你的原话拼装，稳定、免费 | 阶段 0 全量可用 |
| `llm` | DeepSeek 生成叙事，规则引擎仍负责结论 | 有 Key 时，报告更自然 |

渲染：有 Playwright 就用；没有就自动调 Edge/Chrome 无头模式截图，再裁掉底部空白。

跑完会得到：

```
out/A001/
├─ answers.json     # 原始答案（脱敏后的题号映射）
├─ scores.json      # 标签分
├─ report.json      # 报告结构化内容
├─ report.html      # 网页版
├─ report.png       # 长图（微信直接发）
└─ report.pdf       # PDF（客户存档）
```

### 各步骤耗时与成本

| 步骤 | 耗时 | 成本 |
|---|---|---|
| 导入 + 打分 | < 1 秒 | 0 |
| LLM 生成 | 30–60 秒 | 0.15–0.40 元 |
| 质检 | < 1 秒 | 0 |
| 渲染长图/PDF | 5–10 秒 | 0 |
| 人工检查 | 3–5 分钟 | 你的时间 |
| **合计** | **约 1 分钟机器 + 5 分钟人** | **< 0.5 元** |

## 6. 如果想要「提交即出报告」

那是阶段 1 的事，需要：

| 组件 | 作用 |
|---|---|
| 服务器 + 备案域名 | 接收问卷回调 |
| 队列（Redis / 简单文件队列） | 防止并发把 API 打爆 |
| 报告生成服务 | 就是上面那套脚本，包成 HTTP 接口 |
| 通知 | 短信/微信模板消息 |

**或者更简单：直接做小程序。** 支付 → 答题 → 提交 → 页面上直接出报告，30 秒。这是阶段 1 的形态。

## 7. 数据与隐私

- 文件按编号命名（A001），不出现真名
- 不收集手机号、身份证、住址
- 原始答案保留 90 天，可应客户要求删除
- 报告页脚固定免责声明

## 8. 常见问题

| 情况 | 处理 |
|---|---|
| 客户中途退出 | 先让他重进原链接；不行就重发问卷，答案以最新一次为准 |
| 开放题只写了几个字 | 私信追问一次：「能举个具体例子吗？比如上周发生的」 |
| 客户觉得不准 | 先问「哪一条最不像你」，记下来——这是改题的黄金反馈 |
| 客户要退款 | 首次不满意免费重做一份，不退款（虚拟服务） |
| 同一人提交两次 | 以最后一次为准，保留历史版本 |
| 客户问「这是心理测试吗」 | 统一口径：「不是心理测试，是职业方向的自评工具，不出诊断」 |
