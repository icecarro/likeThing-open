## 2 输入与前置检查

1. 项目目录：`D:\python\pythonProject\LikeThing`
2. `DEEPSEEK_API_KEY` 已在环境变量里（生成报告用）

5. 发布用的手机已登录「阿妹聊擅长」，小红书 App 为最新版

## 3 步骤（命令可直接复制）

### 3.1 接咨询（手动）

按 [12 客服话术](12_客服话术与成交SOP.md) 五步走：接住 → 定位 → 翻译 → 给证据 → 给选择。**没问出 3 个具体信息不报价。**

### 3.2 收款（手动）

发 `out\pay_card.png`（收款卡片，图里不出现「微信」字样）。到账后再进行下一步。

### 3.3 开问卷通道并发链接

```powershell
cd D:\python\pythonProject\LikeThing
powershell -ExecutionPolicy Bypass -File scripts\autostart.ps1
Get-Content 问卷\当前链接.txt
```

把链接或 `out\quiz_cover.png` 发给客户。收工后关通道：

```powershell
Get-Process cloudflared -ErrorAction SilentlyContinue | Stop-Process -Force
Get-NetTCPConnection -LocalPort 8799 -State Listen -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

### 3.4 客户提交后出报告

提交会自动落盘到 `out\customers\<手机号>\`；需要手动重跑时：

```powershell
python scripts\generate.py --answers inbox\<编号>.json --id <编号> --mbti <类型> --birth <YYYY-MM-DD> --hour <0-23> --engine llm
```

### 3.5 发笔记（**手动，不用脚本**）

```text
小红书 App → + → 图文 → 传图（按封面/内容/结尾顺序）
→ 粘标题（≤20 字）+ 正文 → 过「发布前检查清单」→ 19:00–21:00 发
```

发布前检查清单（六条全过才发）：

| # | 检查 |
|---|---|
| 1 | 标题 ≤20 字，无「唯一/必须/保证」 |
| 2 | 正文有具体时间、地点、数字，不像模板 |
| 3 | 图片 3–4 张，不追求整齐排版 |
| 4 | 不写精确价，只写「一杯咖啡的钱」 |
| 5 | 距上一条 ≥24 小时 |
| 6 | **手机 App 手动操作，不用网页/脚本** |

### 3.6 抓数据（可自动）

```powershell
cd D:\python\pythonProject\LikeThing
python scripts\xhs_metrics.py
Get-Content out\metrics.csv -Tail 5
```

### 3.7 记 CRM

每单在 `out\crm.md` 追加一行：日期｜来源｜处境｜卡点｜给的话｜报价｜状态｜下一步。

## 7 常见故障与修法

| 现象 | 修法 |
|---|---|
| 问卷链接打不开 | 隧道被停或电脑重启：重跑 `scripts\autostart.ps1` 生成新链接 |
| `generate.py` 报 UTF-8 BOM | 读取用 `utf-8-sig` |
| 数据抓取列对不上 | 卡片顺序固定为 浏览/评论/点赞/收藏/分享 |
| 笔记被处置/不可见 | 先等 24 小时看是否自动恢复，不急着申诉；恢复后一律手动发 |
| 发布按钮点不到 / 点成存草稿 | 已弃用脚本发布，走 App 手动 |
| 手机自动化（adb）连不上 | iPhone 不支持；华为 P40 只暴露 HDB 接口，标准 adb 打不开。**不依赖手机自动化** |
